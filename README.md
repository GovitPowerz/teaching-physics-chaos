# teaching-physics-chaos

Interactive chaos teaching site (planned), sibling of
[kinematics](../kinematics): three canvas tabs - Lorenz attractor, n-link
pendulum, planar gravitational n-body - all demonstrating one idea: same
equations, same integrator, a tiny nudge in initial conditions, a completely
different future. Every tab runs an ensemble of perturbed copies with a live
divergence chart and a fitted Lyapunov exponent. Static site, GitHub Pages.
